How Networks Talk: The OSI and TCP/IP Models

Why this matters. Every networking job, from help desk to data center engineer, uses the layer models as a shared language: "it's a Layer 1 problem" tells a colleague to check the cable, not the firewall. Network+ Domain 1 (Networking Concepts) starts here, and ports and protocols appear on A+, Network+ and Security+ alike.

You will be able to

  • Name network types (LAN, WAN, MAN, PAN, WLAN, SAN, CAN) and topologies, including spine-leaf.
  • List the 7 OSI layers and 4 TCP/IP layers with their PDUs, protocols and devices.
  • Explain encapsulation and the difference between MAC addresses, IP addresses and ports.
  • Describe the TCP handshake, sequence numbers, windowing and teardown, and when UDP is better.
  • Explain Ethernet frames, MTU, jumbo frames, ARP and unicast/multicast/broadcast/anycast.
  • Recall the Network+ port list from memory.

1. What a network is, and the kinds you will meet

A network is two or more devices connected so they can share data. Networks are grouped by the area they cover and by their purpose.

Think of the postal system. Your house (a device) has an address; your street (a LAN) connects neighbors; highways (WANs) connect cities. Letters (data) are put in envelopes (headers) with addresses so every sorting office knows where to send them.

Traditional enterprise networks use a three-tier design (access, distribution, core), or a collapsed core where distribution and core are combined. Traffic flowing between servers inside a data center is east-west; traffic entering or leaving is north-south.

2. The OSI and TCP/IP models side by side

The OSI model (Open Systems Interconnection, ISO/IEC 7498-1) splits networking into 7 layers so each layer has one job and talks only to the layers above and below it. The TCP/IP model (from the IETF RFCs, mainly RFC 1122) is what the internet actually runs, with 4 layers.

Hubs and repeaters are Layer 1 (they just repeat bits). Switches are Layer 2. Routers are Layer 3. A "Layer 3 switch" is a switch that can also route.

3. Encapsulation, and three kinds of address

As data goes down the stack, each layer adds its own header (and Ethernet also adds a trailer). This is encapsulation. The receiver strips them in reverse: decapsulation. Each layer reads only its own header.

IP address = the building's street address. Port = the apartment number. MAC address = the name of the next mail carrier the letter is handed to; it changes at every sorting office.

Port ranges (IANA): 0 to 1023 well-known, 1024 to 49151 registered, 49152 to 65535 dynamic/ephemeral (the random source port your client picks). A socket is IP + protocol + port; a connection is identified by its 5-tuple (source IP, source port, destination IP, destination port, protocol).

4. TCP vs UDP

TCP (Transmission Control Protocol, RFC 9293)

  • Connection-oriented: three-way handshake first.
  • Reliable: sequence numbers, acknowledgments, retransmission.
  • Ordered delivery; flow control with a sliding window; congestion control.
  • 20-byte minimum header.
  • Used by web, email, file transfer, SSH, databases.

UDP (User Datagram Protocol, RFC 768)

  • Connectionless: just send.
  • No acknowledgments or retransmission (the app may add its own).
  • No ordering; very low overhead.
  • 8-byte header.
  • Used by DNS queries, DHCP, TFTP, SNMP, syslog, NTP, VoIP/video, gaming, QUIC (HTTP/3).

Windowing: the receiver advertises how many bytes it can accept before the sender must wait for an ACK. A larger window keeps a long, fast link full. If an ACK doesn't come back before the retransmission timer expires (or three duplicate ACKs arrive), TCP resends the missing segment and slows down.

TCP flags to remember: SYN (start), ACK (acknowledge), FIN (finish), RST (reset), PSH (push now), URG (urgent).

The standard Ethernet MTU (maximum transmission unit) is 1500 bytes. Jumbo frames raise it to about 9000 bytes to cut overhead for storage (iSCSI, NFS) and vMotion traffic, but every device on the path must agree, or packets are fragmented or dropped. Tunnels (VPN, VXLAN) add headers and reduce the usable MTU, a classic cause of "small pages load, big ones hang".

ARP

ARP (Address Resolution Protocol, RFC 826) finds the MAC address for an IPv4 address on the local network: the host broadcasts "Who has 192.168.1.1? Tell 192.168.1.20", and the owner replies by unicast. Results are cached (arp -a). For a remote destination, the host ARPs for its default gateway, not the far host. IPv6 replaces ARP with Neighbor Discovery (ICMPv6).

IPv6 has no broadcast; it uses multicast instead.

Exam trapWhy it is wrong
"Switches work at Layer 3."Standard switches are Layer 2; only multilayer switches route.
"DNS only uses UDP."DNS uses UDP 53 for most queries and TCP 53 for zone transfers and large responses.
"The MAC address stays the same end to end."Each router rewrites the source and destination MACs; IPs stay the same.
