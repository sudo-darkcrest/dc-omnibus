Switches, Routers and the Services That Run Networks

Why this matters. Switches and routers are the heart of every network, and the services around them (time, logging, monitoring, VPNs (Virtual Private Network), QoS (Quality of Service)) keep it running. Network+ Domain 2 (Network Implementation) and Domain 3 (Network Operations) live here. Understanding VLANs (Virtual Local Area Network), spanning tree and routing decisions is what separates "it's broken" from "the trunk is missing VLAN 30".

You will be able to

  • Choose the right network appliance for a job and place it in the OSI (Open Systems Interconnection) model.
  • Explain MAC (Media Access Control) learning, flooding, VLANs, trunks, the native VLAN, STP/RSTP (STP: Spanning Tree Protocol; RSTP: Rapid Spanning Tree Protocol) and LACP (Link Aggregation Control Protocol).
  • Read a routing table, compare static and dynamic routing, and use administrative distance.
  • Describe RIP (Routing Information Protocol), OSPF (Open Shortest Path First), EIGRP (Enhanced Interior Gateway Routing Protocol), BGP (Border Gateway Protocol) and FHRP (First Hop Redundancy Protocol), and network services such as NTP (Network Time Protocol), SNMP (Simple Network Management Protocol), syslog and NetFlow.
  • Compare VPN types, GRE (Generic Routing Encapsulation), MPLS (Multiprotocol Label Switching), SD-WAN (Software-Defined Wide Area Network) and SASE (Secure Access Service Edge), and explain QoS with DSCP (Differentiated Services Code Point), shaping and policing.
  • Produce the core network documents: diagrams, rack diagrams, IP (Internet Protocol) schemes and baselines.

2. Switching: MAC tables, VLANs and loops

A switch learns by reading the source MAC of every frame and noting which port it came in on. It forwards by looking up the destination MAC. If the destination is unknown (or it's a broadcast), it floods the frame out every port in that VLAN except the one it arrived on.

VLANs and trunks

A VLAN (virtual LAN (Local Area Network)) splits one physical switch into separate broadcast domains. An access port belongs to one VLAN and sends untagged frames to the end device. A trunk port carries many VLANs between switches by adding an IEEE (Institute of Electrical and Electronics Engineers) 802.1Q tag (12-bit VLAN ID (Identification): 1 to 4094). The native VLAN is the one VLAN sent untagged on a trunk; both ends must match, and best practice is to change it from VLAN 1 to an unused VLAN to block VLAN hopping. Traffic between VLANs needs a router or Layer 3 switch.

Spanning Tree (STP) and loops

Redundant links create Layer 2 loops; with no TTL (Time To Live) in Ethernet, broadcasts circle forever (a broadcast storm) and MAC tables flap. STP (IEEE 802.1D) blocks just enough ports to make a loop-free tree:

  1. Elect the root bridge: lowest bridge ID = priority (default 32768, in steps of 4096) + MAC address.
  2. Every other switch picks one root port: its lowest-cost path to the root (cost: 10 Mbps 100, 100 Mbps 19, 1 Gbps 4, 10 Gbps 2).
  3. Each link segment gets one designated port: the end closest to the root.
  4. Everything else is blocked (RSTP calls it alternate/backup and "discarding").

Edge features: PortFast/edge ports skip the wait on host ports; BPDU (Bridge Protocol Data Unit) guard shuts a host port that receives switch BPDUs; root guard stops another switch becoming root.

More switch features

  • Link aggregation (LACP, IEEE 802.3ad, now 802.1AX): bundle several links into one logical link for bandwidth and redundancy. STP sees one link.
  • Port mirroring (SPAN): copies traffic from ports or VLANs to a monitor port for an analyzer or IDS.
  • Port security: limit MAC addresses per port, sticky MACs; 802.1X for authentication (Module 16).
  • Jumbo frames, speed/duplex (mismatch = late collisions and slowness), PoE (Power over Ethernet) budgets (Module 11).

3. Routing

A router keeps a routing table of destination prefixes, next hops, metrics and sources. It always chooses the longest prefix match (most specific route). If several sources offer the same prefix, it trusts the one with the lowest administrative distance (AD); within one protocol, the lowest metric wins. A default route (0.0.0.0/0, "gateway of last resort") catches everything else.

Static vs dynamic

Static routes are typed by an admin: simple, predictable, no overhead, but they don't adapt when links fail. Dynamic protocols exchange routes and recalculate automatically. A floating static route has a higher AD so it is used only as a backup.

5. Quality of Service

When a link is congested, packets wait in queues. Voice and video suffer from latency (delay), jitter (variation in delay) and loss; a file download barely notices. QoS classifies and marks traffic, then queues it so sensitive traffic goes first.

  • Marking: DSCP (6 bits in the IP header). Voice = EF (Expedited Forwarding) (46), interactive video ≈ AF41 (34), best effort = 0. Layer 2 uses CoS (3-bit 802.1p in the 802.1Q tag).
  • Queuing: priority/low-latency queuing for voice, weighted fair queuing for the rest.
  • Shaping buffers excess traffic to smooth it to a rate (adds delay, no loss); policing drops or re-marks traffic over the rate (no delay, causes loss).
  • Targets for VoIP: one-way latency < 150 ms, jitter < 30 ms, loss < 1%.

Key terms

Memory aids

Switches learn the Source, forward on the Destination: "Learn from where you came, deliver where you're going."
STP election: lowest wins everything (lowest bridge ID = root, lowest cost = root port, lowest ID breaks ties).
AD order: "Connected Static EBGP EIGRP OSPF IS-IS RIP IBGP" (0, 1, 20, 90, 110, 115, 120, 200): "Cats Sleep Every Evening, Owls Investigate Rats Indoors".
Syslog 0 to 7: "Every Awesome Cisco Engineer Will Need Ice cream Daily".
Shaping shifts (delays) excess; Policing Punishes (drops) it.
Exam trapWhy it is wrong
"VLANs on different switches can talk with no router if both switches have the VLAN."Same VLAN across a trunk: yes. Different VLANs always need Layer 3 routing.
"The switch with the highest priority becomes root."Lowest bridge ID wins; set priority lower (e.g., 4096) to make a switch root.
"Static routes reroute around failures."They don't adapt unless you configure a floating static backup.
"SNMPv2c is secure because it uses a community string."Community strings travel in cleartext; use SNMPv3 (authPriv).
"Policing adds delay."Shaping delays; policing drops.
"A router chooses the route with the lowest AD first."Longest prefix match comes first; AD only breaks ties between sources for the same prefix.
