Cisco Networking and the CCNA

Why this matters. Cisco equipment runs a large share of enterprise networks, and the CCNA (Cisco Certified Network Associate) is one of the most requested networking certifications in job adverts. Network+ (Modules 9 to 13) gave you the concepts. This module turns them into Cisco practice: how to move around IOS, configure switches and routers, read a routing table, write ACLs (Access Control List) and understand network automation.

You will be able to

  • Navigate Cisco IOS modes and save configurations correctly.
  • Configure and verify VLANs (Virtual Local Area Network), trunks, spanning tree and EtherChannel.
  • Read a routing table and predict path selection using longest prefix and administrative distance.
  • Explain DHCP (Dynamic Host Configuration Protocol) relay, NAT/PAT (NAT: Network Address Translation; PAT: Port Address Translation), NTP (Network Time Protocol), SNMP (Simple Network Management Protocol) and syslog severity levels.
  • Write and place standard and extended ACLs, and describe controller-based networking and REST APIs (Application Programming Interface).

2. Cisco IOS basics: modes, prompts and saving your work

Cisco devices run an operating system called IOS (or IOS XE on newer gear). You manage them through a console cable, SSH (Secure Shell) or a web interface, but the exam focuses on the command-line interface (CLI). The prompt tells you which mode you are in, and each mode allows different commands.

ModePromptHow to get thereUsed for
User EXECSwitch>Log inBasic, read-only checks such as ping
Privileged EXECSwitch#enableAll show commands, saving, rebooting, debugging
Global configurationSwitch(config)#configure terminalSettings for the whole device (hostname, passwords, routing)
Interface configurationSwitch(config-if)#interface g0/1Settings for one port (IP address, VLAN, shutdown)
Line configurationSwitch(config-line)#line vty 0 15Console and remote-login settings

Commands you will use constantly

  • show running-config: the configuration in use right now (stored in RAM (Random Access Memory)).
  • show startup-config: the configuration loaded at boot (stored in NVRAM).
  • copy running-config startup-config (or write memory): save changes so they survive a reboot.
  • show ip interface brief: a one-line summary of each interface, its IP address and whether it is up.
  • show version: IOS version, uptime and hardware.
  • exit goes back one level; end or Ctrl+Z returns to privileged EXEC.
  • ? lists available commands, and Tab completes a partly typed command.

Basic security on a new device

  • hostname SW1 names the device.
  • enable secret ... sets a hashed password for privileged mode (prefer it over the older enable password).
  • Configure SSH (a domain name, RSA (Rivest-Shamir-Adleman) keys, a local user, and transport input ssh on the VTY lines) and disable Telnet, which sends passwords in clear text.
  • banner motd shows a legal warning at login.
The most common real-world mistake: making changes and forgetting to save. After a power cut, the device boots from the startup configuration and the changes are gone.

3. Switching on Cisco: VLANs, trunks and spanning tree

Module 12 explained why we use VLANs and trunks. The CCNA expects you to configure and verify them.

FeatureWhat it doesKey commands
VLANSplits one switch into separate Layer 2 networksvlan 10, name STAFF, show vlan brief

Trunk portCarries many VLANs between switches using 802.1Q tagsswitchport mode trunk, show interfaces trunk

EtherChannelBundles several links into one logical link (LACP (Link Aggregation Control Protocol) or Cisco's PAgP)channel-group 1 mode active
Port securityLimits which or how many MAC addresses can use a portswitchport port-security maximum 2
CDP (Cisco Discovery Protocol) and LLDP (Link Layer Discovery Protocol)Discover neighbouring devices (CDP is Cisco's; LLDP is the open standard)show cdp neighbors, show lldp neighbors

Spanning tree elects a root bridge (lowest bridge ID (Identification): priority, then MAC address). Each other switch picks its best path to the root (root port), each link segment gets one designated port, and remaining redundant ports are blocked. Set the root deliberately with a lower priority on your core switch instead of letting the oldest switch win by having the lowest MAC address.

If two switches can't pass traffic for some VLANs, check that both ends are trunking, that the native VLAN matches, and that the VLAN is allowed on the trunk.

4. Routing on Cisco: static routes, OSPF and redundancy

IP Connectivity is the biggest CCNA domain. Here are the essentials beyond Module 12.

Reading the routing table

show ip route lists every known network with a code showing where it came from: C connected, L local (the router's own address), S static, O OSPF (Open Shortest Path First), D EIGRP (Enhanced Interior Gateway Routing Protocol), and S* for a static default route. The router always picks the longest matching prefix first; if two sources offer the same prefix, it prefers the lower administrative distance.

Route sourceAdministrative distance
Connected0
Static1
eBGP20
EIGRP (internal)90
OSPF110
RIP (Routing Information Protocol)120
iBGP200

Static and default routes

  • ip route 10.20.0.0 255.255.0.0 192.168.1.2 sends traffic for 10.20.0.0/16 to the next hop 192.168.1.2.
  • ip route 0.0.0.0 0.0.0.0 203.0.113.1 is a default route ("everything else goes to the ISP (Internet Service Provider)").
  • A floating static route has a higher administrative distance so it is used only if the main route disappears.

OSPF (single area) in brief

  • OSPF is a link-state protocol: routers share a map of the network and each runs the shortest-path-first algorithm.
  • Neighbours must agree on area, subnet, hello and dead timers, and authentication before they become adjacent.
  • Each router has a router ID (set it manually, or the highest loopback IP, or highest active interface IP).
  • On shared Ethernet segments, a DR (designated router) and BDR reduce update traffic; the highest priority wins, then the highest router ID.
  • Cost = reference bandwidth ÷ interface bandwidth. The default reference is 100 Mbps, so set it higher on modern networks so 1 and 10 Gbps links get different costs.
  • Verify with show ip ospf neighbor and show ip route ospf.

First hop redundancy

PCs have one default gateway. HSRP (Hot Standby Router Protocol) (Cisco), VRRP (Virtual Router Redundancy Protocol; open standard) and GLBP (Gateway Load Balancing Protocol; Cisco, load-balancing) let two routers share a virtual gateway IP so one can take over if the other fails.

Administrative distance only breaks ties between different sources for the same prefix. A more specific prefix always wins first, even if it comes from a source with a higher distance.

6. Security fundamentals: ACLs, device hardening and wireless

An access control list (ACL) is an ordered list of permit and deny rules applied to an interface, inbound or outbound.

  • Standard ACLs (numbers 1 to 99 and 1300 to 1999) match only the source IP address. Place them close to the destination so they don't block too much.
  • Extended ACLs (100 to 199 and 2000 to 2699) match source, destination, protocol and port. Place them close to the source to drop unwanted traffic early.
  • Named ACLs work the same way but are easier to read and edit.
  • Rules are checked top to bottom; the first match wins.
  • Every ACL ends with an invisible implicit deny any. An ACL with only deny lines blocks everything.
  • ACLs use wildcard masks, the inverse of a subnet mask: /24 is 0.0.0.255, and host 10.1.1.5 means one address.

Other security topics

  • Layer 2 protections: port security, DHCP snooping (blocks rogue DHCP servers), Dynamic ARP (Address Resolution Protocol) Inspection (blocks ARP poisoning).
  • AAA (Authentication, Authorization, Accounting) with RADIUS (Remote Authentication Dial-In User Service) or TACACS (Terminal Access Controller Access-Control System)+ for central device logins (Module 16).
  • Wireless: lightweight access points managed by a wireless LAN (Local Area Network) controller (WLC), WPA2 and WPA3 personal and enterprise (Module 13).
  • VPNs (Virtual Private Network): site-to-site and remote-access IPsec (Internet Protocol Security) concepts.
If you apply an ACL to permit one host and forget a final permit line, every other host is blocked by the implicit deny. Always ask: "what happens to traffic that matches nothing?"

7. Automation and programmability

Modern networks are increasingly managed by software instead of typing commands on each device. The CCNA covers the concepts.

ConceptMeaning
PlanesData plane forwards traffic; control plane decides where traffic goes (routing protocols, STP (Spanning Tree Protocol)); management plane is how admins configure and monitor.
Controller-based / SDNA central controller (such as Cisco Catalyst Center, formerly DNA Center) holds policy and pushes configuration to devices. Northbound APIs face apps and admins; southbound APIs face devices.
REST APIsWeb-style APIs using HTTP (HyperText Transfer Protocol) verbs that map to CRUD: POST = create, GET = read, PUT/PATCH = update, DELETE = delete. Responses are usually JSON (JavaScript Object Notation).
JSONA text data format of key-value pairs in braces, lists in square brackets: {"hostname": "SW1", "vlans": [10, 20]}
Configuration management toolsAnsible (agentless, uses SSH, YAML playbooks), Puppet and Chef (agent-based), and Terraform (infrastructure as code, declarative).
AI (Artificial Intelligence) and machine learning in networkingAnalytics that spot anomalies and predict problems; newer exam versions mention them conceptually.
Traditional networking is like adjusting the thermostat in every room by hand. Controller-based networking is a smart home app: set the policy once and every room follows it.

How to get hands-on

  • Cisco Packet Tracer: a free network simulator from Cisco's Networking Academy. Ideal for VLAN, routing and ACL practice.
  • Cisco Modeling Labs or other emulators run real IOS images for more advanced labs.
  • Used equipment: a couple of older switches and routers make a good home lab, but check power use and noise.
  • Subnetting speed: the CCNA is timed; practise until you can subnet in your head (Module 10).
A practical plan: Network+ concepts first (Modules 9 to 13), then this module, then two to three months of daily Packet Tracer labs before booking the CCNA.
