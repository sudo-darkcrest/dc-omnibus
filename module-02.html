The Language of Tech: Core Terms, Numbers and Units

Why this matters. Half of all exam mistakes are vocabulary mistakes: mixing up bandwidth and throughput, bits and bytes, or MB (Megabyte) and MiB. Every later module assumes you can read a hex MAC address, convert a subnet mask to binary and work out how long a download takes. Learn the language once here and the rest of the guide becomes much easier to read.

You will be able to

  • Define the core terms used across A+, Network+ and Security+ in plain words and precisely.
  • Convert between binary, decimal and hexadecimal by hand.
  • Tell bits from bytes and decimal prefixes (GB) from binary prefixes (GiB), and explain why a "1 TB (Terabyte)" drive shows about 931 GiB.
  • Calculate download times correctly from a file size and a link speed.
  • Explain ASCII (American Standard Code for Information Interchange), Unicode and UTF-8 (Unicode Transformation Format 8-bit), and read the truth tables for the basic logic gates.

1. Core vocabulary

These words appear in every exam. Each one is given in plain words first, then precisely.

DriverA translator between the OS and a device.Software that lets the operating system control a specific hardware device through a standard interface.
KernelThe core of the operating system.The privileged part of the OS that manages CPU scheduling, memory, devices and system calls.
VirtualizationPretend computers inside a real one.Abstracting hardware so multiple virtual machines share one physical host, managed by a hypervisor.
CloudRenting computing over the internet.On-demand, self-service, elastic, metered computing resources accessed over a network (NIST (National Institute of Standards and Technology) SP (Special Publication) 800-145).
A highway. Bandwidth is the number of lanes. Throughput is how many cars actually pass per hour (traffic jams reduce it). Latency is how long one car takes to drive from end to end. Adding lanes does not make one car arrive faster.
"Upgrade the bandwidth to fix lag in a video call." If the problem is latency or jitter (variation in latency), more bandwidth may not help at all.

2. Number systems

A number system (or base) is how many digits you count with before you carry to the next column. We use base 10 because we have ten fingers. Computers use base 2 because a transistor is either off or on.

Inside a chip, a transistor acts as a switch controlled by voltage. A low voltage is read as 0 and a high voltage as 1. Two clearly separated states are easy to tell apart even with electrical noise, which is why binary is reliable. Each 0 or 1 is a bit (binary digit).

Place values

In any base, each column is worth the base raised to a power. In binary the eight columns of a byte are worth 128, 64, 32, 16, 8, 4, 2, 1. To convert binary to decimal, add the place values where there is a 1: 11001000 = 128 + 64 + 8 = 200.

To convert decimal to binary, subtract the biggest place value that fits and write a 1, otherwise 0. 200 − 128 = 72 (1), 72 − 64 = 8 (1), 32 no (0), 16 no (0), 8 yes (1), then 0, 0, 0 → 11001000.

Hexadecimal shortcut

One hex digit is exactly 4 bits (a nibble), so two hex digits are one byte. Split binary into groups of four: 1100 1000 → C 8. That is why MAC addresses (48 bits) are written as 12 hex digits, like 00:1A:2B:3C:4D:5E.

3. Units: bits, bytes and prefixes

Lowercase b means bit. Uppercase B means byte. 1 B = 8 b. Data rates are usually quoted in bits per second (Mbps, Gbps); file and storage sizes in bytes (MB, GB).

Decimal vs binary prefixes

The International System of Units (SI) prefixes kilo, mega, giga and tera mean powers of 10. Because memory comes in powers of 2, the IEC (International Electrotechnical Commission; IEC 80000-13) defined separate binary prefixes: kibi, mebi, gibi, tebi.

A drive maker sells "1 TB" = 1,000,000,000,000 bytes. Windows divides by 230 but labels the result "GB", so it shows 1012 ÷ 1,073,741,824 ≈ 931 GB (really 931 GiB). Nothing is missing. macOS has used decimal units since 10.6, so it shows 1 TB. RAM (Random Access Memory) is always sold in binary sizes (a 16 GB stick is 16 GiB).

Download time math

Time = size in bits ÷ rate in bits per second. A 1 GB file on a 100 Mbps link: 1 GB = 8,000,000,000 bits; ÷ 100,000,000 bps = 80 seconds at best, more in practice because of protocol overhead (often 5 to 10%).

Forgetting the factor of 8. "100 Mbps should download 100 MB per second" is wrong: 100 Mbps is about 12.5 MB/s.

4. Character encoding

Character encoding is the agreed mapping between characters (letters, digits, emoji) and numbers, so text can be stored as bytes.

  • ASCII (American Standard Code for Information Interchange, 1963): 7 bits, 128 characters. "A" = 65 = 0x41, "a" = 97 = 0x61, "0" = 48 = 0x30, space = 32. Upper and lower case differ by exactly 32 (one bit).
  • Unicode: one universal list of over 150,000 characters across scripts and emoji. Each character has a code point written U+XXXX (for example U+00E9 é, U+1F600 😀). Unicode is the list; encodings decide how code points become bytes.
  • UTF-8: a variable-length encoding of Unicode using 1 to 4 bytes per character. The first 128 code points are identical to ASCII and use one byte, so old ASCII text is valid UTF-8. It is the default on the web (well over 95% of pages). Defined in RFC (Request for Comments) 3629.
  • UTF-16: 2 or 4 bytes per character; used inside Windows and Java.

5. Logic basics

A logic gate is a tiny circuit that takes one or more bits in and produces one bit out according to a rule. Gates are built from transistors, and everything a CPU does is built from gates. The rules come from Boolean algebra (George Boole, 1854; applied to circuits by Claude Shannon, 1937).

ABANDORNANDNORXOR
0000110
0101101
1001101
1111000
  • NOT flips one input: 0 → 1, 1 → 0.
  • AND: output 1 only if all inputs are 1. OR: 1 if any input is 1.
  • NAND (Not-AND) / NOR (Not-OR): AND / OR followed by NOT. NAND alone can build every other gate ("universal gate"); NAND flash memory is named after it.
  • XOR (exclusive OR): 1 if the inputs differ. XOR is used in parity (RAID (Redundant Array of Independent Disks) 5, Module 5) and in many ciphers (Module 16).
Subnet masks work by AND: IP address AND mask = network address (Module 10). A half adder adds two bits: Sum = A XOR B, Carry = A AND B. Chain adders together and you can add any numbers: that is the start of an ALU (Arithmetic Logic Unit; Module 4).

7. Worked examples: the math you will actually do

Module 2 introduced the units. This section shows the handful of calculations that come up again and again on exams and at work, step by step.

1. How long will this download take?

A 4.7 GB file over a 100 Mbps connection. Convert bytes to bits first (multiply by 8), then divide by the speed.

  • 4.7 GB × 8 = 37.6 gigabits = 37,600 megabits
  • 37,600 Mb ÷ 100 Mbps = 376 seconds ≈ 6 minutes 16 seconds
  • Real life is about 10% slower because of protocol overhead, so expect about 7 minutes.

2. Why does my 2 TB drive show 1.81 TB?

The maker counts 2 × 1012 bytes. Windows divides by 240 (1,099,511,627,776) but still labels it "TB".

  • 2,000,000,000,000 ÷ 1,099,511,627,776 ≈ 1.82 TiB, which Windows shows as about 1.81 TB after formatting overhead.

3. How much power does this rack draw?

Power (watts) = volts × amps. A server drawing 2.5 A at 208 V uses 520 W. Ten of them use 5,200 W, or 5.2 kW. Over a year that is 5.2 kW × 8,760 hours = 45,552 kWh. At $0.12 per kWh, about $5,466 a year, before cooling (Module 22).

4. Converting a number between bases

Hexadecimal 0xC8: C = 12, so 12 × 16 + 8 = 200 in decimal. In binary, each hex digit is four bits: C = 1100, 8 = 1000, so 0xC8 = 1100 1000. This is exactly how MAC addresses and IPv6 addresses are written (Modules 9 and 10).

The most common exam mistake is mixing bits and bytes. Network speeds use small b (bits per second). File sizes use capital B (bytes). One byte is eight bits.

8. How big is a gigabyte, really?

Units only become useful when you can picture them. These everyday reference points make storage and bandwidth numbers feel real.

SizeRoughly equals
1 byteOne letter of plain English text
1 KB (kilobyte)A short paragraph
1 MB (megabyte)A one-minute MP3 song, or a 400-page plain-text book
1 GB (gigabyte)About 20 minutes of HD (High Density) video, or 250 phone photos
1 TB (terabyte)About 250,000 photos or 500 hours of HD video
1 PB (petabyte)A large company's entire file storage; a mid-size data center hall holds many
1 EB (exabyte)Big cloud providers store hundreds of these

Speeds work the same way. A 1 Gbps home fiber link moves about 110 to 120 megabytes per second in practice. That fills a 1 TB drive in roughly 2.5 hours. A 400 Gbps data center link (Module 11) moves the same terabyte in about 20 seconds.

Bandwidth is the width of a highway (how many cars can travel side by side). Latency is how long one car takes to drive from one end to the other. Adding lanes does not make the trip shorter.
