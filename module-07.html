Home Computing and Consumer Tech

Why this matters. Everyone becomes the family IT person eventually, and A+ tests SOHO (small office/home office) networking, wireless security and personal device support directly. Homes are also where many attacks start: a reused password, a cheap camera with default credentials, an old router. This module turns you into the person who sets up a home network properly and keeps the household safe.

You will be able to

  • Explain modem vs router vs access point vs mesh, and compare ISP connection types.
  • Configure a home router securely: SSID, WPA3, guest network, DHCP, port forwarding, firmware and parental controls.
  • Choose between Wi-Fi, Zigbee, Z-Wave, Thread and Matter for smart home devices, and isolate IoT safely.
  • Read a device spec sheet and match it to the user's needs.
  • Protect a household with password managers, MFA, updates, backups and phishing awareness.
  • Fix common home problems: slow Wi-Fi, dead spots, printer and charging issues.

1. Setting up a home network

DevicePlain meaningWhat it really does
ModemThe translator between your home and the ISP's line.Modulates/demodulates the ISP's signal (cable DOCSIS, DSL). For fiber, the equivalent is the ONT (optical network terminal).
RouterThe traffic director between your home network and the internet.Routes between your LAN and the ISP (WAN), performs NAT, runs a DHCP server, DNS forwarding and a firewall.
SwitchAdds more wired ports.Forwards Ethernet frames between devices on the same LAN by MAC address (Module 12).
Access point (AP)Makes the Wi-Fi.Bridges wireless clients onto the wired LAN.
Mesh systemSeveral Wi-Fi boxes that work as one network.Multiple nodes sharing one SSID, with wireless (or wired, "Ethernet backhaul") links between nodes and coordinated roaming.

Most ISPs supply a "gateway" that combines modem, router, switch and AP in one box. You can put it in bridge mode to use your own router instead.

Router settings checklist

  1. Change the default admin password (and username if possible); disable remote administration from the WAN.
  2. Update firmware (enable automatic updates if available). Replace routers that no longer get updates.
  3. Set the SSID (network name). Hiding it gives no real security.
  4. Use WPA3-Personal (SAE), or WPA2/WPA3 transition mode for older devices, with a long passphrase. Never WEP or WPA (TKIP).
  5. Disable WPS (its PIN method can be brute-forced).
  6. Enable a guest network with client isolation for visitors, and ideally a separate network or VLAN for IoT.
  7. DHCP: the router hands out addresses (e.g. 192.168.1.100 to .199). Use DHCP reservations so printers and NAS boxes keep the same IP.
  8. Port forwarding: maps an external port to an internal device (e.g. TCP 25565 to a game server). Only forward what you need. Disable UPnP if you do not need devices to open ports automatically.
  9. Parental controls / content filtering: schedules and DNS-based filtering.
  10. Change the default LAN range if it clashes with a VPN, and consider setting custom DNS servers.

Matter (from the Connectivity Standards Alliance, first released 2022) is not a radio: it is an application-layer standard that runs over Wi-Fi, Ethernet and Thread so devices work across Apple Home, Google Home, Amazon Alexa and SmartThings.

  • Voice assistants, smart TVs, cameras, doorbells, thermostats and plugs all collect data. Review privacy settings, microphone and camera permissions, and vendor update policies.
  • Risks: default passwords, no updates, cloud account takeover, devices used in botnets (Mirai, 2016).
  • Segment IoT onto its own SSID/VLAN or guest network so a compromised bulb cannot reach your laptop.

3. Home media

  • Streaming: 4K streams need roughly 15 to 25 Mbps each; wire the TV with Ethernet if Wi-Fi is weak.
  • NAS (network attached storage): a small file server with drives (often RAID 1 or 5) for backups and media. Still keep an off-site copy.
  • Media servers (Plex, Jellyfin, Kodi) organize and stream your own files.
  • HDMI-CEC (Consumer Electronics Control): one remote controls several HDMI devices.
  • ARC / eARC (enhanced Audio Return Channel): sends audio from the TV back down the HDMI cable to a soundbar or receiver; eARC supports lossless and object-based formats such as Dolby Atmos (TrueHD).

4. Choosing personal devices

  • Laptop: portable, battery; choose by CPU class, RAM (16 GB is a sensible minimum for most users now), SSD size, screen, weight and battery life.
  • Desktop: more power per dollar, upgradeable, better cooling; best for gaming and heavy editing.
  • Tablet: media, reading, light work, drawing.
  • Phone: always with you; pick by OS ecosystem, update support length, camera and battery.

5. Personal security at home

  • Passwords: long passphrases (four or more random words, 16+ characters) beat short complex ones. Never reuse passwords; use a password manager (it generates and fills unique passwords and spots phishing domains).
  • MFA (multifactor authentication): add an authenticator app, a hardware security key or a passkey. SMS codes are better than nothing but can be stolen by SIM swapping.
  • Phishing at home: fake delivery texts, "your account is locked" emails, tech-support scam pop-ups and calls. Go to the site yourself instead of clicking links; never let a caller remote into your PC.
  • Updates: OS, browser, router and apps. Enable automatic updates.
  • Backups: 3-2-1 (Module 6), with one copy offline or versioned in the cloud to survive ransomware.
  • Antivirus: built-in Microsoft Defender is good; macOS has XProtect. Avoid "cleaner" apps.
  • Safe browsing: check for HTTPS but remember HTTPS does not mean a site is honest; use an ad/tracker blocker; download only from official sources.
  • Kids and older relatives: parental controls, separate standard (non-admin) accounts, app store restrictions, scam-call awareness, credit freezes, and a trusted person to ask before paying anyone.

7. Power at home

  • Surge protector: diverts voltage spikes using MOVs (metal oxide varistors). Rated in joules (higher is better) and clamping voltage (lower is better). MOVs wear out with each surge. A plain power strip has no protection.
  • UPS (uninterruptible power supply): a battery that keeps devices running through outages and brownouts long enough to save work and shut down cleanly. Size it in VA and W (Module 18). Put the modem, router and NAS on a small UPS to keep internet up during short outages.
  • Battery care (lithium-ion): avoid heat and staying at 100% for long periods (use optimized/limited charging), avoid deep discharges, recycle properly, and never use a swollen battery.

Key terms

Memory aids

Modem Meets the ISP, Router Routes (and NATs), Switch Spreads ports, AP Adds air.
Router hardening: P-F-W-G → change the Password, update Firmware, use WPA3 (disable WPS), add a Guest/IoT network.
Smart home: Z-Wave is the Wave below Wi-Fi (sub-GHz, goes through walls); Zigbee and Thread buzz at 2.4; Matter is the shared language on top.
Exam trapWhy it is wrong
"Hiding the SSID secures Wi-Fi."The SSID is still visible in probe traffic; use WPA3 and a strong passphrase.
"MAC filtering stops attackers."MAC addresses are easily spoofed. It is a minor hurdle at most.
"A power strip protects against surges."Only a surge protector (or UPS with protection) does.
"Matter is a wireless radio."Matter is an application standard over Wi-Fi, Thread and Ethernet.
"P@ssw0rd! is strong because it has symbols."Predictable substitutions are in every cracking dictionary; length and randomness matter more.
