PC Hardware: Every Part and How It Connects

Why this matters. Hardware is the largest single domain on A+ Core 1, and it is what you touch every day in desktop support and data center work. You need to identify every part, know what fits with what (sockets, RAM (Random Access Memory) generations, form factors, power connectors) and replace parts safely. This module goes component by component, then lets you build a PC (Personal Computer), break a RAID (Redundant Array of Independent Disks) array and run a laser printer.

You will be able to

  • Identify motherboard form factors, sockets, slots and headers, and configure key BIOS/UEFI (BIOS: Basic Input/Output System; UEFI: Unified Extensible Firmware Interface) settings.
  • Choose compatible CPUs (Central Processing Unit), coolers, RAM and storage, and calculate RAID capacity and fault tolerance.
  • Select a power supply by wattage, efficiency and connectors.
  • Identify ports, cables and display types by sight and by spec.
  • Describe the 7-step laser printing process and fix common printer problems.
  • Work safely: ESD (electrostatic discharge), electrical safety, lifting and disposal.

1. Motherboards and firmware

The motherboard is the main circuit board: everything plugs into it and it carries power and data between parts.

Form factorSizeExpansion slotsTypical use
ATX (Advanced Technology eXtended)12 × 9.6 in (305 × 244 mm)Up to 7Standard desktops, workstations
microATX (mATX)9.6 × 9.6 in (244 × 244 mm)Up to 4Smaller desktops; fits ATX cases too
mini-ITX6.7 × 6.7 in (170 × 170 mm)1Small form factor, home theater PCs
  • CPU socket: must match the CPU. Intel uses LGA (land grid array: pins in the socket), e.g. LGA 1700 (12th to 14th gen) and LGA 1851 (Core Ultra 200S). AMD desktop uses AM4 (PGA, pin grid array: pins on the CPU) and AM5 (LGA, DDR5 (Double Data Rate) only).
  • Chipset: sets features such as overclocking, number of USB (Universal Serial Bus) and SATA (Serial Advanced Technology Attachment) ports and extra PCIe (Peripheral Component Interconnect Express) lanes (Module 4).
  • Slots: DIMM (Dual Inline Memory Module) slots for RAM, PCIe x1/x4/x16 slots, M.2 slots (keyed M for NVMe/SATA (NVMe: Non-Volatile Memory Express) SSDs (Solid-State Drive), E for Wi-Fi cards).
  • Headers: front-panel connectors (power switch, reset, LEDs (Light-Emitting Diode)), USB headers, fan headers (3-pin DC (Direct Current), 4-pin PWM (Pulse-Width Modulation)), audio, RGB (Red, Green, Blue), TPM (Trusted Platform Module) header on some boards.
  • CMOS (Complementary Metal-Oxide-Semiconductor) battery: a CR2032 coin cell keeps the real-time clock and (on older boards) settings. Symptom of a dead one: the clock resets to a default date, and settings reset after power loss.

BIOS/UEFI settings you must know

  • Boot order: which device the firmware tries first (USB, NVMe, network/PXE).
  • Secure Boot: only signed bootloaders can run (needed for Windows 11).
  • TPM (Trusted Platform Module): a chip or firmware module (Intel PTT (Platform Trust Technology), AMD fTPM) that stores keys for BitLocker and boot measurements. Windows 11 requires TPM 2.0.
  • Virtualization support: Intel VT-x (Virtualization Technology) / AMD-V (and VT-d / AMD-Vi for device passthrough) must be enabled for hypervisors.
  • Passwords: a supervisor/administrator password protects settings; a user/boot password is required before booting.
  • Other: fan curves, XMP/EXPO (XMP: Extreme Memory Profile; EXPO: Extended Profiles for Overclocking) memory profiles, enabling/disabling onboard devices, USB permissions, boot-time intrusion detection.

2. CPUs and cooling

Match the CPU to the socket and the chipset/BIOS version. Desktop CPUs are rated by cores/threads, base and boost clock, cache and TDP (thermal design power: the heat, in watts, the cooler must remove at base load; real boost power can be much higher).

  • Heat sink and fan: metal fins conduct heat away; the fan moves air across them.
  • Thermal paste (thermal interface material) fills microscopic gaps between the CPU's heat spreader and the cooler. Replace it whenever the cooler is removed. Thermal pads are used on VRMs (Voltage Regulator Module) and memory.
  • Liquid cooling: an all-in-one (AIO) loop pumps coolant from a cold plate to a radiator. Watch for pump failure and leaks.
  • Symptoms of poor cooling: thermal throttling (slowdowns), sudden shutdowns, loud fans.

DDR5 DIMM288 (notch in a different place)1.1 V4800 MT/s and up; two 32-bit subchannels per module; on-module power management (PMIC); on-die ECC (Error-Correcting Code)

  • DIMM vs SODIMM: full-size desktop modules vs small outline laptop modules.
  • ECC (error-correcting code) memory detects and corrects single-bit errors; used in servers. Registered (buffered) ECC is common in servers. DDR5's on-die ECC protects only inside the chip; it is not full ECC.
  • Channels: install matching pairs in the color-coded slots (often A2 and B2) for dual channel. Quad and more channels are for workstations and servers.
  • Speed and timings: MT/s (megatransfers per second; DDR4-3200 = 3200 MT/s) and CAS (Column Address Strobe) latency (CL16). Real latency in ns = CL (Column Address Strobe latency) × 2000 ÷ MT/s.
  • Mixing speeds works, but everything runs at the slowest module's speed.

4. Storage and RAID

  • HDD (Hard Disk Drive): spinning magnetic platters and a moving read/write head. Speeds of 5,400, 7,200, 10,000 or 15,000 RPM (Revolutions Per Minute). Form factors 3.5" (desktop/server) and 2.5" (laptop). Cheap per TB (Terabyte); slow random access; sensitive to shock.
  • SSD: NAND (Not-AND) flash, no moving parts. Interfaces: SATA (2.5" or M.2, max ~550 MB/s (MB: Megabyte) because SATA III is 6 Gbps) and NVMe over PCIe (M.2 or U.2/E3.S in servers; several GB/s (GB: Gigabyte)).
  • M.2 is a form factor, not a protocol: an M.2 slot can carry SATA, NVMe or both. Check the board manual and the key (M key, B key, B+M). Sizes are named by width and length: 2280 = 22 mm × 80 mm.
  • Flash types: SLC (Single-Level Cell) (1 bit per cell, most durable), MLC (Multi-Level Cell) (2), TLC (Triple-Level Cell) (3), QLC (Quad-Level Cell) (4, cheapest, lowest endurance). Endurance is rated in TBW (terabytes written) or DWPD (drive writes per day).
  • Other: flash drives and memory cards (SD (Secure Digital), microSD), optical drives (CD (Compact Disc) 700 MB, DVD (Digital Versatile Disc) 4.7 GB single layer, Blu-ray 25 GB per layer).

RAID

RAID (redundant array of independent disks) combines several drives to gain speed, redundancy or both. RAID is not a backup: deleting a file or ransomware affects every disk at once.

LevelHowMin disksUsable capacity (n disks of size S)Survives
RAID 0Striping, no redundancy2n × S0 failures
RAID 1Mirroring2S (for a 2-disk mirror)1 failure (n − 1 for wider mirrors)
RAID 5Striping with distributed parity (XOR)3(n − 1) × S1 failure
RAID 6Striping with double distributed parity4(n − 2) × S2 failures
RAID 10 (1+0)Stripe across mirrored pairs4n × S ÷ 21 per mirror pair (at least 1, up to n/2)
Parity is computed with XOR (Module 2). If D1 XOR D2 XOR D3 = P, any one missing value can be recomputed from the others. While a RAID 5 array rebuilds after a failure, it has no redundancy left, and rebuilding large disks takes many hours, which is why RAID 6 is preferred for big arrays.

5. Expansion cards and GPUs

  • Common cards: video (GPU), sound, network (NIC (Network Interface Card), Wi-Fi), capture cards, storage controllers (RAID/HBA), USB expansion.
  • A card fits any physically larger PCIe slot (x1 card in x16 slot), but runs at the lanes the slot actually wires. PCIe is backward and forward compatible between generations; the link runs at the lower generation.
  • Graphics: integrated GPUs share system RAM; dedicated GPUs have their own VRAM (Video Random Access Memory; GDDR6/GDDR7 (GDDR: Graphics Double Data Rate)) and often need extra power connectors (8-pin PCIe or 12V-2x6).

6. Power supplies

A PSU (Power Supply Unit) converts wall AC (Alternating Current) (110 to 120 V or 220 to 240 V; most modern units are auto-switching) into the DC voltages components need.

  • Rails: +12 V (CPU, GPU, drives' motors, fans), +5 V (USB, some drive logic), +3.3 V (some motherboard and M.2 logic). Plus +5 V standby (keeps wake-on-LAN and USB charging alive when "off").
  • Connectors: 24-pin ATX main; 4+4 or 8-pin EPS (Entry-level Power Supply specification) CPU power; 6+2-pin PCIe (75 W per 6-pin, 150 W per 8-pin) and the 16-pin 12V-2x6 (revised 12VHPWR, up to 600 W) for GPUs; SATA power (15-pin, includes 3.3 V); Molex (4-pin, legacy).
  • Wattage: add the components' draw and leave headroom (aim for 50 to 80% load at peak, for efficiency and growth).
  • 80 PLUS efficiency ratings (115 V internal, at 20/50/100% load): White 80/80/80%, Bronze 82/85/82%, Silver 85/88/85%, Gold 87/90/87%, Platinum 90/92/89%, Titanium 92/94/90% (Titanium also 90% at 10% load).
  • Modular (detachable cables), semi-modular (fixed 24-pin/EPS) or non-modular. Redundant hot-swappable PSUs are standard in servers.
Never open a PSU. Capacitors can hold a dangerous charge long after it is unplugged. Replace the whole unit.

9. Printers and peripherals

Laser printers: the 7 steps

  1. Processing: the printer builds an image of the page in memory (raster image).
  2. Charging: the primary charge roller (or corona wire) puts a uniform negative charge on the photosensitive drum.
  3. Exposing: the laser discharges the areas where the image should be.
  4. Developing: negatively charged toner sticks to the discharged areas of the drum.
  5. Transferring: the transfer roller (or belt) gives the paper a positive charge that pulls toner onto it; static is then removed.
  6. Fusing: heat (~200 °C) and pressure melt the toner into the paper.
  7. Cleaning: a blade wipes leftover toner and an erase lamp removes remaining charge from the drum.

Other printer types

  • Inkjet: thermal (heated bubble) or piezoelectric heads spray ink. Maintenance: clean or align heads, replace cartridges, calibrate.
  • Thermal: heat-sensitive paper (receipts, labels). Maintenance: clean the heating element with isopropyl alcohol; replace paper.
  • Impact (dot matrix): pins strike an inked ribbon; prints multipart (carbon) forms; tractor-feed paper.
  • 3D printers: filament (FDM, Fused Deposition Modeling: PLA (Polylactic Acid), ABS (Acrylonitrile Butadiene Styrene), PETG (Polyethylene Terephthalate Glycol)) or resin (SLA). Maintenance: level the bed, clean the nozzle, keep filament dry.
  • Laser maintenance kits contain a fuser, transfer roller and pickup rollers; reset the page counter after installing.

10. Laptops and mobile devices

  • Replaceable parts (varies by model): battery, RAM (if SODIMM, not soldered), M.2 SSD, Wi-Fi card, keyboard, display, speakers, fans. Always use the service manual, track screws on a magnetic mat and disconnect the battery first.
  • Docking: docking stations and port replicators over USB-C/Thunderbolt add displays, Ethernet and power with one cable.
  • Mobile connectivity: cellular (4G/5G, eSIM), hotspot and tethering, Wi-Fi, Bluetooth (pair: enable, make discoverable, select, enter or confirm PIN, test), NFC (Near Field Communication) (contactless payments, pairing, a few centimeters), GPS (Global Positioning System) location services.
  • Accessories: touch pens, headsets, speakers, webcams, trackpads, drawing pads.
  • Device sync, MDM (Mobile Device Management) enrollment and app management are covered in Module 6.

11. Safety

  • ESD (electrostatic discharge) can destroy chips with a spark you cannot feel (under ~3,000 V). Use an ESD wrist strap connected to ground or the chassis, an ESD mat, anti-static bags, and hold parts by their edges. Low humidity increases ESD risk.
  • Electrical safety: unplug before opening a PC; never open PSUs or CRT (Cathode Ray Tube) monitors; remove jewelry; use equipment grounding; know where circuit breakers are.
  • Lifting: lift with your legs, keep your back straight, get help for heavy items (commonly above about 50 lb / 23 kg), use carts.
  • Disposal: batteries (lithium-ion can catch fire), toner, CRTs and circuit boards go to approved recycling, following local regulations.
  • SDS (safety data sheet; older name MSDS (Material Safety Data Sheet)): describes a chemical's hazards, handling, first aid and disposal, such as toner or cleaning fluids.

12. Building a PC step by step

Knowing the parts is one thing. Putting them together in the right order, safely, is what the A+ performance-based questions test. Here is the order professionals use.

  1. Prepare. Work on a hard, non-carpeted surface. Wear an ESD (Electrostatic Discharge) wrist strap clipped to bare metal. Keep parts in their anti-static bags until needed.
  2. Check compatibility first. CPU socket matches the motherboard, RAM generation matches the slots (DDR4 or DDR5), the case fits the board size, and the PSU (Power Supply Unit) has enough watts plus about 30% headroom.
  3. Install the CPU on the motherboard outside the case. Line up the triangle mark, lower it in with no force, close the lever.
  4. Install the cooler. Apply a pea-sized dot of thermal paste if the cooler has none pre-applied. Plug the fan into the CPU_FAN header.
  5. Install RAM. Use the slots the manual recommends for dual channel (often the second and fourth slots). Press until both clips snap.
  6. Install the M.2 SSD on the board while it is easy to reach.
  7. Mount the board in the case on standoffs, after fitting the I/O shield if it is separate.
  8. Install the PSU and connect the 24-pin ATX and 8-pin CPU power cables.
  9. Install the graphics card in the top full-length PCIe slot and connect its power cables.
  10. Connect the front-panel wires (power switch, reset, LEDs, USB, audio) using the manual's diagram.
  11. First boot. Enter the UEFI setup, confirm the CPU, RAM and drive are detected, enable the memory profile (XMP or EXPO), then install the operating system.
If a new build powers on but shows nothing: reseat the RAM, check the 8-pin CPU power cable, and make sure the monitor is plugged into the graphics card, not the motherboard's video port.

13. Laptops and mobile devices: repair basics

Laptops pack the same parts into a tiny space, so repairs need more care. A+ Core 1 expects you to know what is usually replaceable and how to work safely.

PartUsually replaceable?Notes
BatteryOften, sometimes glued inDisconnect it first before any internal work. Swollen batteries are a fire risk.
RAMSometimesMany thin laptops solder RAM to the board; others use SODIMM slots or the newer CAMM2 modules.
SSDUsuallyMost use M.2; check the length (2230, 2242, 2280).
Wi-Fi cardSometimesAntenna wires run up into the screen lid.
ScreenYes, by a careful techOrder the exact panel part number. Touchscreens include a digitizer layer.
KeyboardYes, but can be riveted to the caseSpills are the most common cause of failure.
  • Keep screws organised (a magnetic mat or a labelled tray). Laptop screws differ in length; a long screw in the wrong hole can pierce the board.
  • Take photos before you disconnect each cable.
  • Ribbon cables use small latches: lift the latch, never pull the cable.
Phone and tablet repairs follow the same rules but often need heat to soften adhesive. Many manufacturers now offer official repair guides and parts programs, so check before buying third-party parts.
