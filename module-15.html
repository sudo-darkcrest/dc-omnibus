Advanced Cisco: CCNP Security and the CCIE

Why this matters. Cisco's professional and expert certifications sit near the top of every salary list. They are earned on the job, after the CCNA (Cisco Certified Network Associate), by engineers who run real firewalls, VPNs (Virtual Private Network) and access control. This module explains what those exams cover, how the security technologies fit together, and what it really takes to earn a CCNP (Cisco Certified Network Professional) or CCIE (Cisco Certified Internetwork Expert).

You will be able to

  • Explain the CCNA, CCNP and CCIE structure, including core, concentration and lab exams.
  • Compare IPsec (Internet Protocol Security), DMVPN (Dynamic Multipoint VPN), FlexVPN and remote access VPNs.
  • Describe next-generation firewalls, IPS (Intrusion Prevention System) and flow-based visibility.
  • Explain 802.1X, MAB (MAC Authentication Bypass), profiling, posture and TrustSec using ISE.
  • Describe cloud, email, web and endpoint security controls and basic security automation.

Cert map

1. Cisco's professional and expert tracks

The CCNA (Module 14) is Cisco's associate level. Above it sit the CCNP (Cisco Certified Network Professional) and the CCIE (Cisco Certified Internetwork Expert). Both are on the lists of top-paying IT (Information Technology) certifications because they prove deep, hands-on skill and usually take years of work to earn.

CCNP Security

The core exam is SCOR 350-701 (Implementing and Operating Cisco Security Core Technologies), 120 minutes. You then pick one concentration exam, such as secure firewall, identity services (ISE), email security, web security, VPNs, or security automation.

CCIE Enterprise Infrastructure

You first pass the CCNP Enterprise core exam, ENCOR 350-401 (architecture, virtualization, infrastructure, network assurance, security and automation). Then you sit an 8-hour lab: a design module followed by a deploy, operate and optimize module, at a Cisco lab location. Many candidates need more than one attempt. A CCIE number is a lifetime identifier, but the certification must be renewed every three years.

Exam codes and weights as published at time of writing. Cisco revises exams regularly; check cisco.com before booking.

2. Security concepts at the professional level

SCOR assumes Security+ (Modules 16 to 18) and goes further into how things work on the wire.

VPN technologies

TechnologyWhat it isUse it for
IPsec site-to-siteEncrypted tunnel between two gateways. IKE (Internet Key Exchange) negotiates keys; IKEv2 (Internet Key Exchange version 2) is the modern versionConnecting offices
DMVPN (Dynamic Multipoint VPN)Hub-and-spoke design where spokes can build tunnels to each other on demandMany branches without configuring every pair
FlexVPNCisco's IKEv2-based framework that unifies site-to-site and remote accessNew deployments that want one consistent configuration
Remote access VPN (TLS/DTLS or IKEv2)A client on a laptop builds a tunnel to the firewallHome and travelling workers
  • IKE phase 1 builds a secure management channel and authenticates the peers (pre-shared keys or certificates). Phase 2 builds the IPsec security associations that carry user traffic.
  • ESP (Encapsulating Security Payload) encrypts and authenticates. AH (Authentication Header) authenticates only and breaks with NAT (Network Address Translation), so it is rarely used.
  • Perfect forward secrecy uses a fresh Diffie-Hellman exchange so one stolen key doesn't unlock past sessions.

Common attacks the exam names

Know the attack and the Cisco-style defence: DHCP (Dynamic Host Configuration Protocol) starvation and rogue DHCP (DHCP snooping), ARP (Address Resolution Protocol) spoofing (Dynamic ARP Inspection), MAC (Media Access Control) flooding (port security), VLAN (Virtual Local Area Network) hopping (disable DTP (Dynamic Trunking Protocol), unused native VLAN), SQL (Structured Query Language) injection and cross-site scripting (web application firewall), DNS (Domain Name System) tunnelling (DNS-layer security), and phishing (email security plus user training).

Analogy. CCNA teaches you to build the roads. CCNP Security teaches you to run the checkpoints, the armoured convoys (VPNs) and the ID badge system for everyone who drives on them.

3. Network security: firewalls, IPS and visibility

From packet filters to next-generation firewalls

GenerationDecides usingExample
Packet filter (ACL)Addresses and ports, one packet at a timeRouter ACL (Module 14)
Stateful firewallTracks each connection so return traffic is allowed automaticallyCisco ASA
Next-generation firewall (NGFW)Adds application identity, user identity, URL (Uniform Resource Locator) categories, intrusion prevention and malware checksCisco Secure Firewall Threat Defense
  • Intrusion prevention (IPS) inspects traffic against signatures and behaviour rules and drops attacks inline. Cisco's engine is based on the open-source Snort project.
  • Management: firewalls are usually managed centrally (on-premises management center or a cloud-delivered manager) so policies stay consistent.
  • Deployment modes: routed (the firewall is a hop with IP (Internet Protocol) addresses) or transparent (it sits invisibly in a Layer 2 path). High availability pairs two firewalls as active/standby; clustering combines several for throughput.
  • TLS decryption lets the firewall see inside encrypted traffic. It needs certificates on clients and a clear privacy policy, and some categories (banking, health) are usually excluded.

Visibility: you can't defend what you can't see

  • NetFlow (and IPFIX (Internet Protocol Flow Information Export)) records who talked to whom, when, how much and on which port, without capturing the content. Analytics tools baseline normal behaviour and flag anomalies such as a server suddenly sending gigabytes to an unknown country.
  • Syslog and SNMP (Simple Network Management Protocol) (Module 14) feed the SIEM (security information and event management system).
  • Segmentation: VLANs, VRFs (virtual routing and forwarding instances), firewall zones and microsegmentation limit how far an attacker can move.
Exam trap. An IDS (intrusion detection system) only alerts, usually from a copy of traffic. An IPS sits inline and can block. Inline means it can also break traffic if it fails closed.

4. Secure network access: 802.1X, ISE and TrustSec

Plugging into a wall port or joining Wi-Fi should not automatically grant access. Network access control checks who and what is connecting first.

  1. 802.1X: the device (supplicant) presents credentials to the switch or access point (authenticator), which passes them by RADIUS (Remote Authentication Dial-In User Service) to a policy server (authentication server). Until it succeeds, the port only allows authentication traffic.
  2. MAB (MAC Authentication Bypass): for printers, cameras and other devices with no 802.1X client, the switch uses the device's MAC address as its identity. MAC addresses can be faked, so MAB devices get limited access.
  3. Profiling: the policy server works out what a device is (an IP phone, a printer, a Windows laptop) from DHCP, CDP/LLDP (CDP: Cisco Discovery Protocol; LLDP: Link Layer Discovery Protocol) and other clues.
  4. Posture: checks that a laptop is patched and runs endpoint protection before giving full access. Non-compliant devices go to a remediation network.
  5. Authorization result: the server tells the switch which VLAN, downloadable ACL or security group tag to apply.
  6. Change of Authorization (CoA): if something changes, such as malware detected, the server can re-authenticate or quarantine the session instantly.

Cisco's policy server is Identity Services Engine (ISE). TrustSec assigns security group tags (SGTs) based on role ("Finance", "Contractor") and enforces policy by tag instead of by IP address, which makes rules survive address changes. pxGrid lets ISE share identity context with firewalls and other tools.

Rollouts usually start in monitor mode (log failures but allow access), then low-impact mode, then closed mode. Going straight to closed mode is how help desks get flooded.

5. Cloud, content and endpoint security

Securing the cloud

  • Shared responsibility (Module 23): the customer always secures data, identities and configuration.
  • DNS-layer security blocks connections to malicious domains before a connection is made, wherever the user is. Cisco's service is Umbrella, now part of its Secure Access platform.
  • SASE and SSE: secure access service edge combines networking (SD-WAN) and cloud-delivered security; security service edge is the security half: secure web gateway, CASB (cloud access security broker), zero trust network access (ZTNA) and firewall as a service.
  • DevSecOps: security checks built into code pipelines (scanning code, containers and infrastructure as code).

Content security: email and web

  • Email security gateways filter spam, malware and phishing, sandbox attachments, rewrite links, and support data loss prevention and encryption.
  • Email authentication: SPF (Sender Policy Framework) lists which servers may send for a domain; DKIM (DomainKeys Identified Mail) signs messages; DMARC (Domain-based Message Authentication, Reporting and Conformance) tells receivers what to do when SPF or DKIM fail, and sends reports.
  • Secure web gateways (web proxies) filter URLs by category and reputation, scan downloads and enforce acceptable use.

Endpoint protection and detection

  • EPP (endpoint protection platform) blocks known malware. EDR (endpoint detection and response) records behaviour so analysts can investigate and isolate a host. XDR (Extended Detection and Response) joins endpoint, network, email and cloud signals.
  • Retrospective detection: if a file judged clean later turns out malicious, the system traces everywhere it went.
  • MDM (mobile device management) and patching keep endpoints compliant (Module 6).

6. Automation and programmability for security

Both CCNP tracks expect basic automation. Security teams automate because attacks move faster than people clicking through consoles.

  • REST APIs (Application Programming Interface) (Module 14): firewalls, ISE and cloud security tools expose APIs. A script can add a malicious IP to a block list across every device in seconds.
  • Python is the common scripting language. Know how to read a simple script that sends an HTTP (HyperText Transfer Protocol) request with an authentication token and parses a JSON (JavaScript Object Notation) reply.
  • NETCONF and RESTCONF configure devices using structured data models (YANG). Ansible and Terraform apply configuration as code.
  • SOAR (security orchestration, automation and response) runs playbooks: enrich an alert, quarantine a host through ISE, open a ticket, notify the team.
  • Telemetry: streaming telemetry pushes device data continuously instead of waiting for SNMP polls.
Exam trap. HTTP status codes: 200 OK, 201 created, 204 no content, 400 bad request, 401 unauthorized (not authenticated), 403 forbidden (authenticated but not allowed), 404 not found, 500 server error.

7. How people actually earn CCNP and CCIE

  • Order: CCNA, then two to three years on the job, then the CCNP core exam, then one concentration. The core exam also qualifies you to book the matching CCIE lab.
  • Labs: Cisco Modeling Labs, Cisco dCloud demos, older hardware from resellers, and vendor sandboxes. CCIE candidates often log hundreds of lab hours.
  • Validity: CCNP and CCIE last three years. Renew by passing exams or earning continuing education credits.
  • Cost: the core exam and concentration exams are priced separately, and the CCIE lab costs much more, plus travel. Many employers pay because these certifications support partner status.
  • Alternatives: other vendors have similar tracks (for example Juniper, Palo Alto Networks and Fortinet). Concepts transfer; command syntax doesn't.
Pick the concentration that matches your job. Network security engineers usually choose firewall or ISE; a VPN concentration suits remote-access-heavy organisations.
